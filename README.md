# DALI PAY 💜

> שני אידיוטים. מאזן אחד.

אפליקציית Android לניהול חובות, מוצרים ופרויקטים בין דוד לאלי, עם סנכרון אוטומטי בזמן אמת בין המכשירים.
כל הממשק בעברית ובכיוון RTL.

## טכנולוגיה

- **אפליקציה:** React Native + Expo (SDK 58), בנייה ל-APK אמיתי דרך EAS Build.
- **ענן וזמן אמת:** Supabase (PostgreSQL + Realtime + Auth).
- **הרשאות:** Row Level Security — רק חברי הקבוצה רואים ומשנים נתונים. מחיקה מותרת ליוצר הרשומה או למנהל הקבוצה.
- **שמירת נתונים:** הכול נשמר בענן ולא במכשיר. התנתקות, התקנה מחדש או החלפת מכשיר לא מוחקות כלום.

## מבנה

```
App.js                 כניסה, ניווט תחתון, חיבור לקבוצה
src/                   מסכים: חובות, מוצרים, פרויקטים, הגדרות, התחברות
supabase/schema.sql    טבלאות, הרשאות וסנכרון בזמן אמת
assets/                אייקון, אייקון adaptive ומסך פתיחה
eas.json               פרופילי בנייה ל-APK
```

## הקמה חד-פעמית (כ-15 דקות)

### 1. בסיס נתונים ב-Supabase

1. פתח פרויקט חינמי ב-https://supabase.com.
2. SQL Editor ← New query ← הדבק את כל `supabase/schema.sql` ← Run.
3. Authentication ← Providers ← Email. לנוחות אפשר לכבות את "Confirm email" (אחרת צריך לאשר אימייל בכל הרשמה).
4. Project Settings ← API: העתק את **Project URL** ואת **anon public key**.

### 2. חיבור האפליקציה

ב-`eas.json` החלף את `PUT_SUPABASE_URL_HERE` ו-`PUT_SUPABASE_ANON_KEY_HERE` בשני הערכים (בשני הפרופילים).
ה-anon key מיועד להיות ציבורי, ההגנה היא בהרשאות ה-RLS שבסכמה.

### 3. בניית APK מהטלפון (GitHub Actions, בלי מחשב ובלי חשבון Expo)

1. ב-GitHub: Settings ← Secrets and variables ← Actions ← New repository secret.
   שם: `KEYSTORE_PASSPHRASE`, ערך: סיסמה שתבחר (לפחות 8 תווים, חזקה). **שמור אותה במקום בטוח** — בלעדיה אי אפשר לעדכן את האפליקציה.
2. Actions ← **Build APK** ← Run workflow.
3. כעבור כ-15–25 דקות ייווצר Release חדש בלשונית Releases, עם הקובץ `dali-pay.apk` להורדה והתקנה.

בריצה הראשונה נוצר מפתח חתימה, מוצפן בסיסמה ונשמר ב-`signing/dalipay.jks.enc` בתוך ה-Repository. בריצות הבאות נעשה בו שימוש חוזר, וכך כל עדכון מותקן מעל הקיים בלי למחוק נתונים. **אסור למחוק את הקובץ הזה או לאבד את הסיסמה.**

בנייה חלופית דרך EAS (דורשת חשבון Expo ו-`EXPO_TOKEN`) קיימת ב-`build-apk-eas.yml` ואינה נחוצה.

## הוראות התקנה בטלפון

1. פתח את קישור ה-APK בטלפון (או העבר את הקובץ).
2. אם Android שואל, אשר "התקנה ממקורות לא ידועים" לדפדפן/מנהל הקבצים.
3. התקן ופתח את **DALI PAY**.

## חיבור משתמש נוסף (דוד ואלי)

1. **דוד:** נרשם באפליקציה (אימייל וסיסמה) ← מזין את שמו ← "יצירת קבוצה".
2. בלשונית **הגדרות** מופיע **קוד הזמנה** — שתף אותו עם אלי.
3. **אלי:** מתקין את ה-APK ← נרשם עם אימייל משלו ← מזין את שמו ← "הצטרפות" עם הקוד.
4. מעכשיו כל חוב, מוצר או פרויקט שמתווסף אצל אחד מופיע מיד אצל השני.

## עדכון האפליקציה בעתיד

1. שנה קוד והעלה commit ל-GitHub.
2. הרץ שוב את Build APK ב-Actions ושלח לשניכם את הקישור ל-Release החדש.
3. התקנה **מעל** הגרסה הקיימת שומרת על הכניסה ועל כל הנתונים (הנתונים בענן).
4. שינויי מבנה נתונים: הוסף קובץ SQL חדש ב-`supabase/` והרץ אותו ב-SQL Editor לפני ההפצה.

## גיבוי וייצוא

- **ייצוא ידני:** הגדרות ← "ייצוא נתונים (JSON)" — שולח עותק מלא של נתוני הקבוצה דרך חלון השיתוף.
- **גיבוי בענן:** ב-Supabase ניתן להוריד dump מהדשבורד; גיבויים אוטומטיים יומיים קיימים בתוכניות בתשלום.
